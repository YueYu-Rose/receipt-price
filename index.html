第一步：填入免费的 Gemini API 密钥

  1. 打开 Google AI Studio，用 Google 账号登录
  2. 点 "Create API key"，复制生成的密钥
  3. 点右上角"设置"，粘贴进去保存

密钥只保存在这台手机的浏览器里，不会上传到任何别的地方。

可以连续拍，也可以一次选多张。照片排队自动识别，识别期间请保持这个页面开着。

    规格都知道时按单价比（每 oz / fl oz / 个）；缺规格时按包装价比，只能当参考。价格都是税前的最新一次记录。

    数据只存在这台手机的浏览器里。换手机或清除浏览器数据前，先导出备份。

    设置

    在 aistudio.google.com/apikey 免费申请。只保存在这台手机上。

    默认 gemini-2.5-flash。如果提示模型不存在，可以换成 AI Studio 里列出的其他 Flash 模型。

    注意：Gemini 免费版上传的内容可能会被 Google 用来改进产品。拍照时可以把卡号那部分挡住。
